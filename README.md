# ❄️ Погода в Воркуте

Одностраничный сайт с актуальной погодой в Воркуте (Коми, 67.50° с.ш., 64.03° в.д.).

## Что показывает

- Текущая температура, «ощущается как», состояние погоды
- Ветер и порывы, влажность, давление, осадки, облачность
- График температуры на ближайшие 24 часа
- Почасовой прогноз на 12 часов (с вероятностью осадков)
- Прогноз на 7 дней: max/min, осадки, ветер
- Время рассвета и заката + информация о полярном дне/ночи

## Как работает

Статическая страница (HTML + CSS + JS), данные берутся напрямую из бесплатного API
[Open-Meteo](https://open-meteo.com/) — без ключей и без бэкенда. Автообновление каждые 10 минут.

## Локальный запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```
